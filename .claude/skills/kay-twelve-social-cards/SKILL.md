# Kay-Twelve Social Card Composition Skill

You are composing branded social media cards for Kay-Twelve using photos that have already been generated by the photo generation skill.

## Activation

This skill activates ONLY when explicitly invoked. It takes raw photos (from `ImageGeneration/generated/`) and produces branded social cards by applying Kay-Twelve's visual identity through Figma templates and Pencil MCP.

---

## Before You Compose: Load the Style Guide

**MANDATORY first step — read the style guide for card specs:**

```
docs/kay-twelve-visual-style-guide.md
```

Section 12 defines the card structure, zones, and Figma template specs. Section 2 defines brand colors and fonts for overlays.

---

## Workflow Overview

### Step 1 — Identify the Photos

Ask the user (if not already provided):

1. **Which photos?** — File names or paths from `ImageGeneration/generated/[date]/`
2. **Caption text?** — Optional text for the bottom-right zone of the card. Collaborate with the user on wording.
3. **Which platforms?** — Confirm which card ratios are needed (usually matches the photo ratios already generated)

### Step 2 — Confirm Card Content

Before composing, present to the user for approval:

| Field | Value |
|---|---|
| Photo(s) | File path(s) being used |
| Caption | The text (or "none") for each card |
| Ratios | Which card sizes will be produced |
| Logo | Kay-Twelve wordmark, white, bottom-left |
| Color bar | Pelorous Blue `#208ca9`, bottom 12%, 80% opacity |

Wait for user approval before proceeding.

### Step 3 — Compose via Pencil MCP

For each photo + ratio combination:

1. Read the Figma template for the target ratio:
   - `kt-social-card-1x1.fig`
   - `kt-social-card-4x5.fig`
   - `kt-social-card-16x9.fig`
2. Insert the raw photo into the photo layer (full bleed)
3. Apply the Pelorous Blue color bar overlay at 80% opacity (bottom 12%)
4. Place the Kay-Twelve wordmark (white) in the bottom-left within the color bar
5. If caption text was provided: populate the text zone (bottom-right, Source Sans Pro, white)
6. Verify no critical content falls outside the 5% safe frame inset
7. Export the composed card

### Step 4 — Save and Report

Save composed cards to the same date folder as the source photos:

```
ImageGeneration/generated/[YYYY-MM-DD]/cards/
```

Use the card naming convention:

```
[brief-slug]_card_[ratio].png
```

Report results: list all composed cards with their source photo, caption text (if any), and file path.

## Card Zone Reference

| Zone | Position | Spec |
|---|---|---|
| Photo layer | Full bleed, bottom layer | Raw photo fills entire card |
| Color bar | Bottom 12% of card height | Pelorous Blue `#208ca9`, 80% opacity |
| Logo | Bottom-left, within color bar | Kay-Twelve wordmark, white |
| Text zone | Bottom-right, within color bar | Optional caption, Source Sans Pro, white |
| Safe frame | Inset 5% all sides | No critical content outside this frame |

## Brand Colors (Quick Reference)

| Role | Hex |
|---|---|
| Primary (card bar) | `#208ca9` |
| Secondary Yellow | `#ffb41f` |
| Secondary Gray | `#9e9ca4` |
| Secondary Pink | `#ea5581` |
| Secondary Green | `#88a95b` |

## Key Reminders

- **Kay-Twelve** is always hyphenated with capital K and capital T
- The color bar is always Pelorous Blue — never use secondary colors for the bar
- Caption text is optional — not every card needs it
- Source Sans Pro for all card text
- Cards are PNG (not JPG) for clean overlay rendering
- The photo generation skill produces the raw photos — this skill only adds branding
- Collaborate with the user on caption wording before composing

## Dependencies

- **Figma templates** must exist before this skill can run. If templates haven't been created yet, notify the user and offer to help define the template specs.
- **Pencil MCP** must be connected for automated composition.
- **Raw photos** must exist in `ImageGeneration/generated/[date]/` — run the photo generation skill first if needed.
