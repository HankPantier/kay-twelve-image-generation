End-to-end image workflow — Option C

From a single brief to a full platform-ready social card set. Two one-time setup steps, then the loop is fully automated.

One-time setup (do once, reuse forever)

Setup 1 — Figma

Design master social card templates for each platform ratio (1:1, 4:5, 16:9). Define photo zone, logo position, text zone, brand color bars. Export as Figma components.

Setup 2 — Style Guide

The .md we're building now. Defines shot archetypes, Nano Banana defaults, negative prompts, and composition rules. Claude Code reads this every run.

The repeatable loop — triggered by a single prompt
1

User writes a brief

e.g. "Make me an image for LinkedIn, Instagram, and the blog showing two middle school students collaborating at a flexible table in a bright library space."

2

Claude Code reads the style guide + determines shot type

Identifies archetype (collaboration shot), selects correct Nano Banana defaults (85mm, f/1.4, ISO 400, Portra 400), and notes which platform ratios are needed (1:1, 4:5, 16:9).

3

Nano Banana schemas generated (3 files)

One schema per platform ratio — same subject/scene/style, different meta.aspect_ratio. Sent to Nano Banana for image generation.

1:1 4:5 16:9
4

Photos returned → Pencil composes social cards

Pencil reads the Figma template definitions, drops each photo into the correct card template, applies brand elements (logo, color bar, text zone). Outputs final card files.

5

Deliverables ready

3 raw photos (no branding) + 3 branded social cards, organized by platform. Ready to post or hand off to the team.

Inpainting variant (for real environment photos)

Same loop — except in Step 3, the schema includes input_image pointing to the real environment photo. Nano Banana adds students into the existing space rather than generating from scratch. Card composition in Step 4 is identical.
