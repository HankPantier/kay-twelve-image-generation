Kay-Twelve Visual Style Guide — document structure

12 sections across two layers: the photography layer (what to generate) and the workflow layer (how to generate and compose it). Click any section to flag it for discussion.

Layer 1 — Photography Standards

Defines what on-brand looks like. Read by Claude Code to make generation decisions. Also human-readable for photographers and agency partners.

1

Purpose & scope

What this guide governs, how it's used (AI-first), link to workflow. Short — half a page.

2

Brand visual identity (reference)

Color palette, fonts — for use in social card overlays, not photography direction. Pelorous Blue #208ca9 as primary.

3

Photography philosophy

The Kay-Twelve visual story in words: human-first, clean but lived-in, natural light, storytelling over catalog. The "why" behind every rule that follows.

4

Good vs. bad — annotated examples

The 5 good + 4 bad examples with their reasoning captured as rules. Image paths reference the examples/ folder. AI reads this as pattern recognition training.

5

Shot archetypes

The Space · The Moment · The Collaboration — each with composition rules, when to use, and which examples they map to. Confirmed ✓

6

Composition & safe zone rules

Center-weighted framing, head/foot room requirements for multi-ratio crops. The rules that make one image work at 16:9 and 4:5 simultaneously.

7

Universal negative prompts library

Everything that must never appear: clutter, flash, tape on floor, posed smiles, catalog feel, grainy texture. Applied to every Nano Banana run regardless of archetype.

Layer 2 — Generation Workflow

Defines how to generate. Executable instructions for Claude Code. References Layer 1 at every step.

8

Platform & aspect ratio guide

The mapping table (confirmed ✓). Standard full run = 1:1 + 4:5 + 16:9. 9:16 on demand. Includes output naming conventions.

9

Nano Banana schema defaults (per archetype)

The exact JSON schema blocks for The Space, The Moment, and The Collaboration — including camera, lens, aperture, ISO, film stock, negative prompts. Drop-in templates.

10

Workflow A — full AI generation

Step-by-step: read brief → identify archetype → generate 3 schemas → submit to Nano Banana → receive photos. With example prompt and expected output.

11

Workflow B — inpainting (student insertion)

When to use (real client environment photos, environment/ folder). Schema difference: input_image with path + usage_type. Decision rules for when inpainting vs. full generation.

12

Social card composition (Figma + Pencil)

Figma template spec: photo zone, logo position, text zone, brand color bar. Pencil generation instructions: how to read the template and compose card variants per platform.
